A 100-word monologue from an exhausted dark lord who would rather hand the
crown — ledger, tariffs, dripping tap and all — to the hero than keep ruling.
The tiredness lives in the pauses and deflections, never in a plain statement.

`main.ts` writes the monologue to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output`) and prints it, with a self-checking gate: exactly 100 words, 1–600
characters, verified again by reading the file back from disk.

Run: `node main.ts`
